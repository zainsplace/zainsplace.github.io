One missing check, other people's private AI sessions

A developer platform's AI-agent feature let any low-privilege member read other users' private sessions, because the query behind them never checked who owned the record. Found by reading the authorisation code, proved live on production with two accounts.

Read from source, proved on the live site, confirmed real by the duplicate.

Closed as duplicate · company not named · Aug 2026

An SSRF the docs said couldn't happen

A managed cloud database's snapshot-restore feature could be made to fetch attacker URLs with an ordinary API key, even though the docs said it was blocked in the cloud. Confirmed with 22 out-of-band callbacks, reported with honest bounds.

Found in source, confirmed out-of-band, severity called honestly; confirmed real by the duplicate.

A public API schema that gave away the back office

An unauthenticated schema endpoint on a fintech platform served its whole API spec, internal order workflow and settlement counterparty names included. Real exposure, closed duplicate because another researcher filed it nine days before me.

Confirmed real by the duplicate; company unnamed because it was never disclosed.

Lab, not client work · 12 Oct 2026

Remote trust lab: five Roblox remotes that believed the client

A server script with five RemoteEvents, attacked with the same calls an exploiter would fire: client-chosen coin amounts, negative prices, a race-condition double spend and a self-granted admin rank. Four Critical, one High.

All five fixed, then re-tested against the same attacks.
